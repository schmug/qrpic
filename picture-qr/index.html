Picture QR

Hides an image inside a working QR code. Each module becomes a 3×3 block: the centre pixel carries the data, the other eight are a dither of your picture. Everything runs in this page — nothing is uploaded.

What do these do?

Higher versions add more modules, so the picture gets more detail but the code gets denser to scan. Error correction H also forces a larger version, which helps the picture. Keep the dark colour much darker than the light one.

Scale the PNG only with nearest-neighbour (no smoothing). SVG stays sharp at any size and is best for print. Always test-scan with a phone before printing.
